# Foundational Techniques

The ten foundational prompt engineering techniques form the essential toolkit for working effectively with large language models. These techniques are widely applicable, relatively easy to implement, and produce measurable output quality improvements with minimal effort.

**Who these are for:** Developers, writers, analysts, and researchers who work with LLMs regularly and want to move beyond trial-and-error prompting.

---

## Techniques in This Section

1. [Zero-Shot Prompting](01-zero-shot) — Asking the model to complete a task with no examples
2. [Few-Shot Prompting](02-few-shot) — Providing examples to establish pattern and format
3. [Chain-of-Thought](03-chain-of-thought) — Prompting the model to reason step by step
4. [Role-Play / Persona](04-role-play) — Assigning an expert role to frame the response
5. [Structured Output](05-structured-output) — Requesting specific output formats (JSON, tables, lists)
6. [Negative Constraints](06-negative-constraints) — Specifying what the model should NOT do
7. [Context Injection](07-context-injection) — Supplying relevant background before the task
8. [Audience Specification](08-audience-specification) — Defining who the response is written for
9. [Tone Control](09-tone-control) — Directing the register and emotional quality of writing
10. [Instruction Clarity](10-instruction-clarity) — Writing unambiguous, well-scoped instructions
